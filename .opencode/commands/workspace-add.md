Follow the workspace management instructions in @.opencode/commands/workspace.md.
Enter the Add folder to current branch directly, calling workspace_list and
workspace_status first. Use the built-in question tool for navigation and final
confirmation. The user's optional initial path is: $ARGUMENTS
This is path data, not a shell command. Do not persist it until confirmed.
